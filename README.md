# RD 遠端桌面

自用的遠端桌面工具，功能類似 AnyDesk / TeamViewer：在自己的幾台 Windows 電腦之間互相看畫面、控制滑鼠和鍵盤。

- 每台電腦裝同一個程式 **RD Host**，它同時是被控端和控制端。
- 透過 **Tailscale** 私人網路直接連線，**不需要伺服器、不需要網域**，任何一台關機都不影響其他電腦互連。

## 架構

```
        PC B（控制端）                                  PC C（被控端）
┌──────────────────────┐                        ┌──────────────────────────┐
│ RD Host 遠端視窗       │ ① 配對（WebSocket）     │ RD Host 內建信令（47821）  │
│ 點清單裡的 PC C ───────┼───── Tailscale ───────▶│ 驗證密碼（挑戰-回應）      │
│                      │                        │                          │
│ 解碼顯示畫面 ◀═════════╪═ ② WebRTC 點對點直連 ═══╪═ 擷取螢幕＋H.264 硬體編碼 │
│ 送出滑鼠鍵盤 ══════════╪═══════════════════════▶╪═ SendInput 注入          │
└──────────────────────┘                        └──────────────────────────┘
```

| 項目 | 做法 |
|---|---|
| 畫面 | Chromium WebRTC，優先用 H.264 硬體編碼，最高 60fps |
| 低延遲 | P2P 直連（同一區網時直接走區網）、接收端零緩衝、滑鼠移動走「不重送」的資料通道 |
| 滑鼠鍵盤 | Win32 `SendInput`，送掃描碼（與鍵盤配置無關），支援多螢幕和高 DPI |
| 密碼 | 挑戰-回應（HMAC-SHA256），密碼本身不在網路上傳送；錯 5 次鎖定 1 分鐘 |
| 連線範圍 | 內建信令只接受 Tailscale 位址和本機；安裝時加入只允許 Tailscale 的防火牆規則 |
| 記住密碼 | 驗證成功後才保存，用 Windows DPAPI 加密，只有同一個 Windows 帳號解得開 |
| 安全提示 | 被控制時螢幕上方顯示紅色提示列和「中斷」按鈕（提示列不會出現在傳出的畫面中） |
| 剪貼簿 | 被控端複製的文字自動同步到控制端；控制端按 Ctrl+V 時先把本機剪貼簿同步過去 |

## 安裝

### 1. 每台都安裝 Tailscale

```bash
winget install --id Tailscale.Tailscale -e
```

每台都用**同一個帳號**登入。如果按系統匣圖示沒有跳出登入頁，可以在 PowerShell 用指令登入（路徑有空格，前面要加 `&`）：

```bash
& "C:\Program Files\Tailscale\tailscale.exe" up
```

### 2. 每台都安裝 RD Host

執行 `host\dist\RD Host Setup 0.1.0.exe`。安裝時會要求系統管理員權限，因為要加入一條防火牆規則：只允許 Tailscale 網路的電腦連進 RD Host。

程式沒有數位簽章，如果 SmartScreen 跳出警告，按「其他資訊 → 仍要執行」。

裝好後打開 RD Host，展開「設定」：

- 設定**固定密碼**（至少 8 個字元）
- 勾選**開機時自動啟動**

## 使用

### 控制其他電腦

RD Host 的「控制其他電腦」會自動列出 Tailscale 網路裡的其他 Windows 電腦，綠點代表在線上。

- **第一次**：點電腦名稱，輸入那台的固定密碼，按「連線」。勾選「記住密碼」的話，驗證成功後會加密保存。
- **之後**：點一下名稱就直接連線。
- 清單裡沒有的電腦，可以在下方輸入電腦名稱或 Tailscale IP。
- 要忘記密碼，按名稱旁邊的 ×。

### 遠端畫面視窗

- 滑鼠移到畫面最上緣會出現工具列，可以：
  - 切換螢幕
  - 調整畫質（流暢 / 平衡 / 高畫質 / 區網極速）
  - 切換模式（文字清晰 / 動態流暢）
  - 查看延遲統計
- **全螢幕**模式會鎖定鍵盤，Win 鍵、Alt+Tab 等快捷鍵都會送到遠端。長按 Esc 可以離開全螢幕。
- 「統計」可以看到幀率、位元率、往返延遲，以及目前是直連（P2P）還是走中繼（TURN）。
- 按「中斷」會結束連線並關閉視窗。

### 被控端

- 主視窗上方顯示**本機名稱**（Tailscale 裡的電腦名稱），綠燈「已就緒」代表其他電腦連得到這台。
- 關閉視窗會縮到系統匣，繼續在背景等待連線。要結束程式，請在系統匣圖示按右鍵選「結束」。
- **一次性密碼**每次啟動都會重新產生，也可以按「更換」手動換一組。
- **固定密碼**適合自己的電腦。設定檔只保存衍生金鑰，不保存明文。
- 「開機時自動啟動」只在安裝版有效。

## 已知限制

- **被控的電腦不能鎖定**：UAC 提示和鎖定畫面在 Windows 的「安全桌面」上，一般程式無法擷取或操作。請關掉閒置自動鎖定，也不要按 Win+L。重開機後要先登入 Windows，RD Host 才會啟動。
- **系統管理員權限的視窗**（例如工作管理員）：RD Host 必須同樣以系統管理員身分執行，才能操作這類視窗。
- **Ctrl+Alt+Del** 無法從遠端送出。
- 目前不支援聲音傳輸和檔案傳輸。
- 同一時間只能有一個控制端連線。

## 疑難排解

| 狀況 | 原因與處理 |
|---|---|
| 狀態列顯示「Tailscale 未連線」 | 從系統匣打開 Tailscale 並登入 |
| 清單裡沒有其他電腦 | 那台還沒裝 Tailscale，或登入的帳號不同 |
| 「連不到對方電腦」 | 對方沒開機、RD Host 沒在執行，或用的是免安裝版而防火牆擋住了。請在對方電腦用安裝版 |
| 「密碼錯誤」 | 對方的固定密碼改過了。重新輸入正確密碼，連線成功後會自動更新記住的密碼 |
| 「無法建立連線」 | P2P 打不通。兩台都在 Tailscale 上時通常不會發生，請確認 Tailscale 都是連線狀態 |
| 畫面模糊 | 把畫質調成「高畫質」或「區網極速」，模式選「文字清晰」 |

## 開發

需要 Node.js 20 以上。

```bash
cd host && npm install && npm start
```

打包（產生 `host/dist/` 的安裝版和免安裝版）：

```bash
cd host && npm run dist
```

### 專案結構

```
host/                RD Host（Electron，Windows）
  main.js              主程序：視窗、系統匣、遠端視窗、記住的密碼
  lib/signaling.js     內建信令伺服器（連接埠 47821，只接受 Tailscale 與本機）
  lib/tailscale.js     讀取 Tailscale 狀態與電腦清單
  lib/input.js         滑鼠鍵盤注入（koffi 呼叫 user32.dll）
  lib/auth.js          密碼驗證
  renderer/            主視窗與被控端的 WebRTC
  build/installer.nsh  安裝時加入防火牆規則
server/public/       控制端網頁（打包時複製進 host/viewer-web/）
server/、deploy/、windows/
                     早期的「中央伺服器」版本（瀏覽器控制、Cloudflare / VPS 部署）。
                     目前的 RD Host 不再連到中央伺服器，這些只留作參考。
```
